Engineering highlights

  • ▸Spending data pre-aggregated server-side before AI call — prevents model arithmetic errors on raw transaction lists
  • ▸Loan balance tracked as a running total (no FK between loans and payments) — simpler schema, same query result
  • ▸Weekly budgets stored in localStorage — amber at 80%, red at 100%, no server round-trip
  • ▸Trend chart only plots days with transactions — sparse data renders cleanly without zero-fill noise
